- Data preprocessing and prediction pipeline.
- Interactive frontend with a backend prediction API.
- Focus on making model predictions accessible through a user-friendly interface.

**Tech:** Python, scikit-learn, FastAPI, React, TypeScript, Tailwind CSS

🔗 [View repository](https://github.com/riju27/NEXUS-ESTATE-AI-Property-Intelligence)

### 📊 DATAFLOW — The Living Data Laboratory

An interactive data engineering and SQL analytics application for exploring datasets, transforming raw records, and auditing data quality.

- CSV import and data exploration.
- SQL query workspace.
- ETL pipeline orchestration.
- Missing-value, duplicate, and data-quality analysis.
- PostgreSQL integration with demo-mode fallback.

**Tech:** TypeScript, React, SQL, ETL, PostgreSQL, Express.js

🔗 [View repository](https://github.com/riju27/DATAFLOW-Living-Data-Laboratory)
